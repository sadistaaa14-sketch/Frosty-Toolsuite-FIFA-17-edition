# mapping.txt template - sound banks looked up by pa_player_id + pa_team_type
# 2 bank(s) of the 5,621 the census read are keyed this way (notes/sound_key_census_banks.tsv, 2026-10-19):
#     speech/announcer/announcer_00_eng1/soundwaves/ppa_player_eng.res
#     speech/announcer/announcer_00_eng2/soundwaves/ppa_player_eng.res
#
# Copy this file next to your audio files as mapping.txt and give each file the key it goes under; then
# right-click a clip of the bank in the sound editor and choose Bulk Import From Folder... The editor's
# Write mapping.txt... writes this file for one bank with a line for every clip it has (and Export All
# Clips writes it beside the exported files), which is the easiest start.
#
# One line per file:     file name.wav = parameter=value, parameter=value
# Files are .wav, .mp3 or .ealayer3, named relative to the folder. Lines starting with # are notes.
# A line whose values are the key of a clip the bank has replaces that clip's audio; a key the bank does
# not have adds a clip filed under it. Two lines with one key are its first and second take (take=2
# names one; a take the bank does not have yet is added). clip=3 replaces clip 3 whatever its key.
# A parameter every clip of the bank has one value of may be left out: the line takes that value.
# Every line is checked before anything is written, and the import is one edit of the bank.
#
# pa_player_id: players.playerid
# FIFA17.exe sets it to a match player's players.playerid (+8 of the match player, FUN_146faab90); in pa_LINEUP_PLAYER_SUB the id the substitution message carries, which the exe looks up among the match players by their playerid (FUN_146fe4920).
# Set by the code of pa_LINEUP_PLAYER_SUB, pa_LINEUP_PLAYER, pa_INTRO, pa_LINEUP_TEAM_HOME, pa_SUBSTITUTION_OFF, pa_SUBSTITUTION_ON, pa_GOAL.
#   values these banks use (the census lists up to 60 a bank): 41, 591, 657, 684, 887, 1179, 1219, 1238, 1611, 2147, 2196, 2231, 2335, 2702, 3484,
#     3622, 4098, 4257, 4667, 5355, 5479, 6122, 6826, 7631, 7826, 7939, 8119, 8473, 8517, 9014, 9815, 10899,
#     11141, 11346, 11358, 11381, 11430, 11488, 11728, 11800, 11811, 12259, 13130, 13732, 13739, 13843,
#     13879, 13922, 16177, 16254, 18745, 18919, 19104, 19292, 19324, 19332, 19405, 19410, 19521, 19541,
#     19685, 19699, 19724, 19869, 19874, 20172, 20289, 20775, 20800, 20801, 21146, 23466, 23467, 24630,
#     26501, 26502, 26503, 26504, 26530, 26992, 27532, 29183, 30110, 41236, 41635, 45119, 45197, 45595,
#     45842, 46590, 46736
#
# pa_team_type
# FIFA17.exe sets it to one of three strings, not a number (FUN_147825f00, FUN_14781fd80).
# Set by the code of pa_SUBSTITUTION_OFF, pa_LINEUP_PLAYER_SUB, pa_SUBSTITUTION_ON.
#   value names: invalid=0, home=1, away=2
#   values these banks use (the census lists up to 60 a bank): 1, 2
#
# Example lines (replace the file names and values with yours):
my_clip_01.wav = pa_player_id=41, pa_team_type=1
my_clip_02.wav = pa_player_id=657, pa_team_type=2
