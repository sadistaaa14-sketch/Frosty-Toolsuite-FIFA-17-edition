# mapping.txt template - sound banks looked up by Language + ptw_player_a_contextual_stats
# 4 bank(s) of the 5,621 the census read are keyed this way (notes/sound_key_census_banks.tsv, 2026-10-19):
#     speech/commentary/eng_us/soundwaves/bptw_c_intro_both_dual_contextual.res
#     speech/commentary/eng_us/soundwaves/bptw_c_intro_single_contextual.res
#     speech/commentary/eng_us/soundwaves/eng_us_male/bptw_c_intro_player_a_dual_contextual.res
#     speech/loccommentary/ger_de/soundwaves/ger_de_male/bptw_c_intro_single_contextual.res
#
# Copy this file next to your audio files as mapping.txt and give each file the key it goes under; then
# right-click a clip of the bank in the sound editor and choose Bulk Import From Folder... The editor's
# Write mapping.txt... writes this file for one bank with a line for every clip it has (and Export All
# Clips writes it beside the exported files), which is the easiest start.
#
# One line per file:     file name.wav = parameter=value, parameter=value
# Files are .wav, .mp3 or .ealayer3, named relative to the folder. Lines starting with # are notes.
# A line whose values are the key of a clip the bank has replaces that clip's audio; a key the bank does
# not have adds a clip filed under it. Two lines with one key are its first and second take (take=2
# names one; a take the bank does not have yet is added). clip=3 replaces clip 3 whatever its key.
# A parameter every clip of the bank has one value of may be left out: the line takes that value.
# Every line is checked before anything is written, and the import is one edit of the bank.
#
# Language
# The game's language index (+0x20 of the object at +0x548 of DAT_14472ec30); FIFA17.exe looks a clip up with that index first and with 0 when that finds nothing (FUN_146213800), so a clip under 0 is the one every language without its own falls back to.
#   values these banks use (the census lists up to 60 a bank): 0, 2
#
# ptw_player_a_contextual_stats
# FIFA17.exe sets it to +0x78 of the record FUN_14783c480 is given (a field of the handler's record; what fills it is not traced).
# Set by the code of trigger_PTW_INTRO, trigger_PTW_INTRO_SINGLE_CONTEXTUAL, trigger_PTW_INTRO_DUAL_DEFAULT, trigger_PTW_INTRO_DUAL_CONTEXTUAL, trigger_PTW_HT, trigger_PTW_FT, trigger_PTW_FT_SINGLE_CONTEXTUAL, trigger_PTW_FT_DUAL_DEFAULT and 2 more.
#   value names: invalid=0, 5PLUSGOALS_LAST_MATCH=1, 4GOALS_LAST_MATCH=2, HATTRICK_LAST_MATCH=4,
#     BRACE_LAST_MATCH=8, 4GOALS_IN_LAST_3_MATCHES=16, 3GOALS_IN_LAST_3_MATCHES=32, TOP_SCORER_IN_LEAGUE=64,
#     TOP_SCORER_IN_COMPETITION=128, 2ND_HIGHEST_SCORER_IN_LEAGUE=256, 2ND_HIGHEST_SCORER_IN_COMPETITION=512,
#     MOST_ASSISTS_IN_LEAGUE=1024, MOST_ASSISTS_IN_COMPETITION=2048, DEBUT=4096,
#     5PLUSGOALS_IN_LAST_3_MATCHES=8192
#   values these banks use (the census lists up to 60 a bank): 1, 2, 4, 8, 16, 32, 64, 128, 8192
#
# Example lines (replace the file names and values with yours):
my_clip_01.wav = Language=0, ptw_player_a_contextual_stats=0
my_clip_02.wav = Language=0, ptw_player_a_contextual_stats=0
