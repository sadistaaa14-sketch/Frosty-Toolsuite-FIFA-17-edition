mapping.txt templates for the sound editor's Bulk Import

Bulk Import (right-click a clip in a sound asset, Bulk Import From Folder...) reads a folder's mapping.txt:
one line per audio file, naming the key the file goes under. A key the asset has is replaced, a new one
is added, and the plan is shown before anything is written.

The easiest start is the editor itself: Write mapping.txt... saves the file for the open asset with a line
for every clip it has, and Export All Clips writes it beside the exported WAVs, so an exported folder
imports straight back. These templates are the same file for each group of banks the census found keyed
the same way, for writing a mapping without the editor open.

  EA Trax songs.txt                              EATrax_01 / EATrax_02 (songid and the DB's metadata)
  clip numbers - sound waves and other assets.txt  sound wave assets, the intro and highlights music banks
  index.tsv                                      every bank, its key parameters and its template
