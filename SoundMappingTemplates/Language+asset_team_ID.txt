# Copy this file next to your audio files as mapping.txt and give each file the key it goes under; then
# right-click a clip of the bank in the sound editor and choose Bulk Import From Folder... The editor's
# Write mapping.txt... writes this file for one bank with a line for every clip it has (and Export All
# Clips writes it beside the exported files), which is the easiest start.
#
# One line per file:     file name.wav = parameter=value, parameter=value
# Files are .wav, .mp3 or .ealayer3, named relative to the folder. Lines starting with # are notes.
# A line whose values are the key of a clip the bank has replaces that clip's audio; a key the bank does
# not have adds a clip filed under it. Two lines with one key are its first and second take (take=2
# names one; a take the bank does not have yet is added). clip=3 replaces clip 3 whatever its key.
# A parameter every clip of the bank has one value of may be left out: the line takes that value.
# Every line is checked before anything is written, and the import is one edit of the bank.
#
