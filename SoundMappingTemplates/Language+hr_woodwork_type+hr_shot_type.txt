# mapping.txt template - sound banks looked up by Language + hr_woodwork_type + hr_shot_type
# 3 bank(s) of the 5,621 the census read are keyed this way (notes/sound_key_census_banks.tsv, 2026-10-19):
#     speech/commentary/eng_us/soundwaves/bhr_woodwork_misc.res
#     speech/commentary/eng_us/soundwaves/bhr_woodwork_overhead.res
#     speech/loccommentary/por_br/soundwaves/por_br_demo_neutral/bhr_woodwork_overhead.res
#
# Copy this file next to your audio files as mapping.txt and give each file the key it goes under; then
# right-click a clip of the bank in the sound editor and choose Bulk Import From Folder... The editor's
# Write mapping.txt... writes this file for one bank with a line for every clip it has (and Export All
# Clips writes it beside the exported files), which is the easiest start.
#
# One line per file:     file name.wav = parameter=value, parameter=value
# Files are .wav, .mp3 or .ealayer3, named relative to the folder. Lines starting with # are notes.
# A line whose values are the key of a clip the bank has replaces that clip's audio; a key the bank does
# not have adds a clip filed under it. Two lines with one key are its first and second take (take=2
# names one; a take the bank does not have yet is added). clip=3 replaces clip 3 whatever its key.
# A parameter every clip of the bank has one value of may be left out: the line takes that value.
# Every line is checked before anything is written, and the import is one edit of the bank.
#
# Language
# The game's language index (+0x20 of the object at +0x548 of DAT_14472ec30); FIFA17.exe looks a clip up with that index first and with 0 when that finds nothing (FUN_146213800), so a clip under 0 is the one every language without its own falls back to.
#   values these banks use (the census lists up to 60 a bank): 15
#
# hr_woodwork_type
# FIFA17.exe sets it to 1 or 2: FUN_14781b6b0 passes 1, FUN_14781b670 passes 2.
# Set by the code of trigger_REPLAY_HEAT_WOODWORK, trigger_REPLAY_HEAT_WOODWORK_COLOUR.
#   value names: invalid=0, POST=1, BAR=2, NEAR_POST=4, FAR_POST=8
#   values these banks use (the census lists up to 60 a bank): 1
#
# hr_shot_type
# FIFA17.exe sets it to one bit per value: the exe sends every bit that is set in its flag word as a value of its own (0 when none is).
# Set by the code of trigger_REPLAY_HEAT_GOAL, trigger_SUB_CAMERA, trigger_SUB, trigger_REPLAY_HEAT_WOODWORK, trigger_REPLAY_HEAT_WOODWORK_COLOUR, trigger_REPLAY_MISSED, trigger_REPLAY_HEAT_NEARMISS, trigger_REPLAY_HEAT_NEARMISS_COLOUR and 3 more.
#   value names: invalid=0, CHIP=1, FIRST_TIME_LACES=2, FIRST_TIME_PLACED=4, HEADER=8, LACES=16, PLACED=32,
#     OPEN_GOAL=64, OVERHEAD=128, VOLLEY=256, CROSS=512, DEFLECTION=1024, DIVING_HEADER=2048,
#     BARELY_CHIP=4096, OUTSIDE_FOOT=8192, FLAIR=16384
#   values these banks use (the census lists up to 60 a bank): 128
#
# Example lines (replace the file names and values with yours):
my_clip_01.wav = Language=0, hr_woodwork_type=0, hr_shot_type=0
my_clip_02.wav = Language=0, hr_woodwork_type=0, hr_shot_type=0
