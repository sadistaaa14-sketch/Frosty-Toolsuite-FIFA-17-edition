# mapping.txt template - sound banks looked up by Language + common_notes_ID
# 8 bank(s) of the 5,621 the census read are keyed this way (notes/sound_key_census_banks.tsv, 2026-10-19):
#     speech/commentary/eng_us/soundwaves/bft_whistle_cnotes.res
#     speech/commentary/eng_us/soundwaves/bintroseq3_cnotes_intro.res
#     speech/commentary/eng_us/soundwaves/bintroseq3_cnotes_intro_clash.res
#     speech/commentary/eng_us/soundwaves/bintroseq3_cnotes_intro_eos.res
#     speech/commentary/eng_us/soundwaves/bintroseq3_cnotes_intro_expec_1.res
#     speech/commentary/eng_us/soundwaves/bintroseq3_cnotes_intro_expec_same.res

#     speech/loccommentary/por_br/soundwaves/por_br_neutral/bintroseq3_cnotes_intro.res
#
# Copy this file next to your audio files as mapping.txt and give each file the key it goes under; then
# right-click a clip of the bank in the sound editor and choose Bulk Import From Folder... The editor's
# Write mapping.txt... writes this file for one bank with a line for every clip it has (and Export All
# Clips writes it beside the exported files), which is the easiest start.
#
# One line per file:     file name.wav = parameter=value, parameter=value
# Files are .wav, .mp3 or .ealayer3, named relative to the folder. Lines starting with # are notes.
# A line whose values are the key of a clip the bank has replaces that clip's audio; a key the bank does
# not have adds a clip filed under it. Two lines with one key are its first and second take (take=2
# names one; a take the bank does not have yet is added). clip=3 replaces clip 3 whatever its key.
# A parameter every clip of the bank has one value of may be left out: the line takes that value.
# Every line is checked before anything is written, and the import is one edit of the bank.
#
# Language
# The game's language index (+0x20 of the object at +0x548 of DAT_14472ec30); FIFA17.exe looks a clip up with that index first and with 0 when that finds nothing (FUN_146213800), so a clip under 0 is the one every language without its own falls back to.
#   values these banks use (the census lists up to 60 a bank): 0, 15
#
# common_notes_ID
# FIFA17.exe's code never names it (neither the name nor its id 0x4664DE86 occurs in the exe); the game's CommentaryContextSystemEvents data declares it.
#   values these banks use (the census lists up to 60 a bank): 0, 100, 200, 300, 400, 500, 600, 700, 800, 1000, 1100, 1300, 1400, 1500, 1600,
#     231200, 231400, 1030400, 2010020, 2013320, 2019920, 2020020, 2021520, 2023320, 2025020, 2026620,
#     2029920, 2050002, 2050003, 2050007, 2050008, 2050011, 2050015, 2050016, 2051500, 2051501, 2051502,
#     2051503, 2051504, 2051505, 2051506, 2051507, 2051508, 2051510, 2051511, 2051514, 2051515, 2051516,
#     2053300, 2053301, 2053302, 2053303, 2053304, 2053305, 2053306, 2053307, 2053308, 2053310, 2053311,
#     2053314, 2053315
#
# Example lines (replace the file names and values with yours):
my_clip_01.wav = Language=0, common_notes_ID=0
