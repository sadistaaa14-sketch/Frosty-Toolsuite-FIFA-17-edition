# mapping.txt template - sound banks looked up by pa_time_of_day + pa_league_or_cup_type
# 11 bank(s) of the 5,621 the census read are keyed this way (notes/sound_key_census_banks.tsv, 2026-10-19):
#     speech/announcer/announcer_01_fre/soundwaves/in_int_lg_fre.res
#     speech/announcer/announcer_01_fre/soundwaves/in_inter_league_fre.res
#     speech/announcer/announcer_01_fre/soundwaves/in_league_fre.res
#     speech/announcer/announcer_02_ger/soundwaves/in_int_lg_ger.res
#     speech/announcer/announcer_02_ger/soundwaves/in_inter_league_ger.res
#     speech/announcer/announcer_02_ger/soundwaves/in_league_ger.res
#     speech/announcer/announcer_03_ita/soundwaves/in_int_lg_ita.res
#     speech/announcer/announcer_03_ita/soundwaves/in_inter_league_ita.res
#     speech/announcer/announcer_04_spa/soundwaves/in_int_lg_spa.res

#     speech/announcer/announcer_04_spa/soundwaves/in_league_spa.res
#
# Copy this file next to your audio files as mapping.txt and give each file the key it goes under; then
# right-click a clip of the bank in the sound editor and choose Bulk Import From Folder... The editor's
# Write mapping.txt... writes this file for one bank with a line for every clip it has (and Export All
# Clips writes it beside the exported files), which is the easiest start.
#
# One line per file:     file name.wav = parameter=value, parameter=value
# Files are .wav, .mp3 or .ealayer3, named relative to the folder. Lines starting with # are notes.
# A line whose values are the key of a clip the bank has replaces that clip's audio; a key the bank does
# not have adds a clip filed under it. Two lines with one key are its first and second take (take=2
# names one; a take the bank does not have yet is added). clip=3 replaces clip 3 whatever its key.
# A parameter every clip of the bank has one value of may be left out: the line takes that value.
# Every line is checked before anything is written, and the import is one edit of the bank.
#
# pa_time_of_day
# FIFA17.exe sets it to +0x1c of the object at +0x48 of the announcer handler (FUN_14783f320).
# Set by the code of pa_INTRO, pa_LINEUP_TEAM_HOME, pa_LINEUP_PLAYER.
#   value names: invalid=0, afternoon=1, evening=2
#   values these banks use (the census lists up to 60 a bank): 1, 2
#
# pa_league_or_cup_type
# FIFA17.exe sets it to +0x24 of the object at +0x48 of the announcer handler (FUN_14783f320).
# Set by the code of pa_INTRO, pa_LINEUP_TEAM_HOME, pa_LINEUP_PLAYER.
#   value names: invalid=0, carling_cup=1, fa_cup=2, german_bundesliga_1=4, copa_del_rey=8, european=16,
#     english_fa_preimiership=32, international=64, ligue_de_football_professional_1=128,
#     spanish_primera=256, world_cup=512, world_master=1024, coupe_de_league=2048, deutscher_pokal=4096,
#     ecc=8192, efa=16384
#   values these banks use (the census lists up to 60 a bank): 4, 8, 64, 128, 256, 1024, 2048
#
# Example lines (replace the file names and values with yours):
my_clip_01.wav = pa_time_of_day=1, pa_league_or_cup_type=64
my_clip_02.wav = pa_time_of_day=2, pa_league_or_cup_type=64
