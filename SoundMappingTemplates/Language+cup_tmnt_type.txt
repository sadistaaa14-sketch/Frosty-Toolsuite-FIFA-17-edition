# mapping.txt template - sound banks looked up by Language + cup_tmnt_type
# 4 bank(s) of the 5,621 the census read are keyed this way (notes/sound_key_census_banks.tsv, 2026-10-19):
#     speech/commentary/eng_us/soundwaves/bintroseq1_cup_non_final.res
#     speech/commentary/eng_us/soundwaves/bkickoff_1st_half_cup.res
#     speech/commentary/eng_us/soundwaves/bkickoff_2nd_half_cup.res
#     speech/loccommentary/pol_pl/soundwaves/pol_pl_neutral/bintroseq1_cup_non_final.res
#
# Copy this file next to your audio files as mapping.txt and give each file the key it goes under; then
# right-click a clip of the bank in the sound editor and choose Bulk Import From Folder... The editor's
# Write mapping.txt... writes this file for one bank with a line for every clip it has (and Export All
# Clips writes it beside the exported files), which is the easiest start.
#
# One line per file:     file name.wav = parameter=value, parameter=value
# Files are .wav, .mp3 or .ealayer3, named relative to the folder. Lines starting with # are notes.
# A line whose values are the key of a clip the bank has replaces that clip's audio; a key the bank does
# not have adds a clip filed under it. Two lines with one key are its first and second take (take=2
# names one; a take the bank does not have yet is added). clip=3 replaces clip 3 whatever its key.
# A parameter every clip of the bank has one value of may be left out: the line takes that value.
# Every line is checked before anything is written, and the import is one edit of the bank.
#
# Language
# The game's language index (+0x20 of the object at +0x548 of DAT_14472ec30); FIFA17.exe looks a clip up with that index first and with 0 when that finds nothing (FUN_146213800), so a clip under 0 is the one every language without its own falls back to.
#   values these banks use (the census lists up to 60 a bank): 9
#
# cup_tmnt_type
# FIFA17.exe sets it to one bit per value: the exe sends every bit that is set in its flag word as a value of its own (0 when none is).
# Set by the code of trigger_NH_FULL_TIME, trigger_NH_PRE_MATCH, trigger_INTRO_SEQ1, trigger_INTRO_SEQ2, trigger_INTRO_SEQ2_STORYLINE, trigger_NH_HALF_TIME, trigger_INTRO_REF, trigger_CUP_FINAL_MINOR_SEQ and 14 more.
#   value names: invalid=0, QUATER_LEG_1=262144, QUALIFYING_ROUND=65536, QUALIFIERS_LAST_MATCH=32768,
#     QUALIFIERS_FIRST_MATCH=16384, GROUP_STAGE_MATCH_6=8192, GROUP_STAGE_MATCH_5=4096, QUATER=131072,
#     ROUND_OF_16=33554432, DOMESTIC_CUP=67108864, SUPER_CUP=134217728, CONTINENTAL_CUP=268435456,
#     PROMOTION_PLAYOFF=536870912, RELEGATION_PLAYOFF=1073741824, ANY_GROUP_MATCH=1,
#     FIRST_MATCH_FOR_TEAM=128, FINAL_LEG_2=64, FINAL_LEG_1=32, FINAL=16, ANY_ROUND_LEG_2=8,
#     KNOCK_OUT=16777216, ANY_ROUND=2, GROUP_STAGE_MATCH_2=512, GROUP_STAGE_MATCH_3=1024, ANY_ROUND_LEG_1=4,
#     SEMI_LEG_2=4194304, GROUP_STAGE_MATCH_1=256, SINGLE_GAME_FINAL=8388608, GROUP_STAGE_MATCH_4=2048,
#     SEMI_LEG_1=2097152, SEMI=1048576, QUATER_LEG_2=524288
#   values these banks use (the census lists up to 60 a bank): 2048
#
# Example lines (replace the file names and values with yours):
my_clip_01.wav = Language=0, cup_tmnt_type=0
my_clip_02.wav = Language=0, cup_tmnt_type=0
